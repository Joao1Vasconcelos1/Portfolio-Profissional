# Descrição

Página de portfólio pessoal que apresenta meu perfil profissional, as tecnologias que estudo e os projetos desenvolvidos durante o curso Técnico em Desenvolvimento de Sistemas. A página é responsiva, se adaptando ao computador, tablet e celular.

# Tecnologias utilizadas

**HTML5, CSS3, Bootstrap 5, Devicon, VS Code, Git/GitHub e GitHub Pages.**

Para cada nível ser associado a uma mensagem de alerta e a uma cor, seguindo a progressão de risco, está sendo utilizada a biblioteca **colorama**, permitindo destacar cada situação com uma cor específica.
